## Proyecto

La rama `main` contiene el código fuente, la solución de Visual Studio, el perfil de publicación y la documentación técnica.

La aplicación permite crear, consultar, actualizar y eliminar registros durante una sesión local. Los datos permanecen únicamente en memoria y se eliminan al cerrar la aplicación.

La publicación de Windows utiliza configuración **Release**, **win-x64**, **self-contained** y de **archivo único**.

## Privacidad

El proyecto es académico y no está destinado a almacenar información personal real. No utiliza base de datos, almacenamiento persistente ni servicios externos para conservar los registros.
